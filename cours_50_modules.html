Gestion des erreurs

try/except capture les erreurs pour éviter que le programme plante. finally s'exécute toujours, qu'il y ait erreur ou non.

MODULE 14 / 50

Méthodes magiques

Les dunder methods (__add__, __repr__, __len__) définissent le comportement de l'objet face aux opérateurs et fonctions Python.

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)
    def __repr__(self):
        return f'Point({self.x}, {self.y})'

Interfaces et classes abstraites

Une classe abstraite définit un contrat. On ne peut pas l'instancier. Les sous-classes doivent implémenter les méthodes abstraites.

from abc import ABC, abstractmethod

class Forme(ABC):

    def aire(self): ...

class Carre(Forme):
    def __init__(self, c): self.c = c
    def aire(self): return self.c ** 2

MODULE 22 / 50

Recherche binaire

Sur un tableau trié, on divise par deux à chaque étape. Complexité O(log n). Fondamental.

def recherche_binaire(arr, cible):
    g, d = 0, len(arr) - 1
    while g <= d:
        m = (g + d) // 2
        if arr[m] == cible: return m
        if arr[m] < cible: g = m + 1
        else: d = m - 1
    return -1

Graphes : BFS et DFS

BFS explore par niveau (courte distance). DFS explore en profondeur (composantes connexes).

from collections import deque

def bfs(graphe, start):
    visite, queue = {start}, deque([start])
    while queue:
        n = queue.popleft()
        for v in graphe[n]:
            if v not in visite:
                visite.add(v)
                queue.append(v)
    return visite
MODULE 29 / 50

Programmation dynamique

La programmation dynamique résout les sous-problèmes une seule fois et réutilise les résultats.

def fib(n):
    memo = {0: 0, 1: 1}
    for i in range(2, n + 1):
        memo[i] = memo[i-1] + memo[i-2]
    return memo[n]
MODULE 30 / 50

Algorithme glouton

Le glouton choisit la meilleure option locale à chaque étape. Rapide, mais pas toujours optimal.

def rendu_monnaie(somme, pieces):
    res = []
    for p in sorted(pieces, reverse=True):
        while somme >= p:
            res.append(p)
            somme -= p
    return res

Régression linéaire

Trouve la droite qui passe au plus près d'un ensemble de points. Base de la prédiction simple.

def regression(xs, ys):
    n = len(xs)
    mx = sum(xs) / n
    my = sum(ys) / n
    a = sum((x-mx)*(y-my) for x, y in zip(xs, ys)) / sum((x-mx)**2 for x in xs)
    b = my - a * mx
    return a, b
MODULE 37 / 50

Réseaux de neurones

Un neurone calcule une somme pondérée puis applique une non-linéarité (ReLU). Empilés, ils forment un réseau.

def neurone(entrees, poids, biais):
    z = sum(e * p for e, p in zip(entrees, poids)) + biais
    return max(0, z) # ReLU
MODULE 38 / 50

Descente de gradient

On ajuste les paramètres dans la direction opposée au gradient. La loss diminue à chaque étape.

def gradient_descent(x, y, lr=0.01, epochs=1000):
    a, b = 0, 0
    for _ in range(epochs):
        da = sum((a * xi + b - yi) * xi for xi, yi in zip(x, y))
        db = sum((a * xi + b - yi) for xi, yi in zip(x, y))
        a -= lr * da
        b -= lr * db
    return a, b

MODULE 40 / 50

Embeddings

Un embedding transforme un mot en vecteur. La similarité cosinus mesure l'angle entre deux vecteurs.

def cosine_sim(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = sum(x*x for x in a) ** 0.5
    nb = sum(x*x for x in b) ** 0.5
    return dot / (na * nb)

Threading

Décorateurs

Un décorateur ajoute une fonctionnalité à une fonction sans la modifier. Puissant pour le logging, la sécurité, les caches.

import time

def chrono(f):
    def wrapper(*args, **kwargs):
        t0 = time.time()
        r = f(*args, **kwargs)
        print(f'{time.time() - t0:.2f}s')
        return r
    return wrapper

@chrono
def travail(): time.sleep(1)

Générateurs

Un générateur produit des valeurs à la demande. Utilise yield au lieu de return. Économe en mémoire.

def compter(n):
    i = 0
    while i < n:
        yield i
        i += 1

for x in compter(5):
    print(x)
